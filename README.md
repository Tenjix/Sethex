# Sethex

**Prototype for climate based biome generation.**

This repository contains the experimental code of a prototype described in my master’s thesis and demo video.

**Thesis**: https://tenjix.de/projects/climate-based-biomes/

**Video**: https://youtu.be/dQQqRKGbNKY

It was released as reference without instructions and restrictions after repeated requests.

Uses https://github.com/ocornut/imgui internally.

Requires https://libcinder.org to build.

Would be nice to hear about derivative work.
